## 上线前尚需真实环境验证

- 缺 Apple/Google 商店账号、正式签名及广告配置，未做真实购买/恢复/续费/退款沙盒；本地模拟不替代渠道验收。
- 本机没有完整 Xcode 和已连接的 Android 设备，未生成签名 IPA，也未做手机长时间播放。
- 数据库使用 PGlite：去除 citext/pgcrypto 扩展声明并将 citext 改为 text。非 owner RLS 已测，但仍需 PostgreSQL 16 原始迁移、真实连接池/多进程并发及 Docker 集成复验。
- 总部必须明确选择 gross/net 分成基数与比例；缺净额凭据不推算。旧实付历史需要核对报告，不能自动重记历史收入。
- 源存储版本保留、HLS 图登记、边缘国家签名、代理商独立原生配置和 HTTPS 域名关联文件都需在目标环境配置。
- 紧急下架可阻止后续授权/资源请求，已经缓存在设备内存中的内容不能远程收回。

配置见 [native-integrations-and-cash.md](../native-integrations-and-cash.md)。本批未部署，也不保证“所有上线风险均已排除”。
