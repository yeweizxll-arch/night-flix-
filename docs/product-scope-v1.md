# 首版产品范围

## 规模与平台

- 20～30 个商家，初期低成本部署，架构可扩容至峰值 10,000 人同时在线观看。
- 海外部署，初期目标用户包含日本、美国等市场。
- 用户端支持 H5、Android、iOS；先提供测试安装包，测试完成后再上架。
- Android/iOS 支持合规的资源热更新；原生能力变更仍通过整包升级。

## 多租户与白标

- 商家仅由总后台创建，商家到期时间由平台手动设置。
- 每个商家有平台子域名，也可绑定并自由切换已验证的独立域名。
- 名称、Logo、图标、启动页、主题和接口域名均可配置；正式构建由总后台发起。
- 商家到期后，后台只读且允许导出，用户站点暂停；续期后恢复。
- 用户、订单、资产、历史记录和配置按商家隔离；同一账号可在不同商家分别注册。

## 核心业务

- 公共内容库由平台管理并授权商家；支持单剧授权和内容包授权及到期自动下架。
- 商家可管理私有内容，提交平台审核后发布；支持 CSV/Excel 和视频 URL 批量导入。
- 支持会员、积分充值、整剧购买、单集解锁、免费试看和一级分销佣金。
- 商家可配置独立价格、多币种价格、会员套餐和营销活动。
- 商家可使用自有支付通道，也可使用平台公共通道；公共通道收入进入可提现余额。
- 提现由商家申请、平台人工审核、线下打款并上传凭证。

## 用户与运营

- 用户支持手机号、邮箱、账号密码注册登录；最多同时登录 3 台设备，第 4 台踢掉最早设备。
- 支持搜索、收藏、点赞、追剧、播放历史和跨 H5/App 同步。
- 播放器支持倍速、选集、自动连播、横竖屏和断点续播；仅在线播放。
- 支持评论、一级回复、弹幕、敏感词自动过滤、举报和一级恢复。
- 支持站内消息、按商家独立配置的移动推送、群发频控和退订。
- 支持内置工单，以及商家电话、邮箱、微信二维码等联系方式。
- 用户可注销；个人信息匿名化，依法需要的订单和财务记录解除身份关联后保留。

## 国际化与扩展

- 首版语言：简体中文、繁体中文、英语、法语、日语、韩语。
- UI 与剧目、分类、公告、政策、套餐等业务内容均支持翻译和默认语言回退。
- 支持人民币、美元、欧元、日元、韩元等；商家手动设置各币种价格，订单固化币种和金额。
- 默认支付适配微信支付、支付宝、Stripe、PayPal、Apple IAP，并允许新增第三方适配器。

## 明确不做

- 首版不做小程序、离线下载、投屏、自动转码、自动水印、自动截图和复杂个性化推荐。
- 用户端不提供退款申请入口；仅保留受权限控制的后台异常退款。
- 不迁移旧包里的用户、订单、支付凭据和运行日志。
