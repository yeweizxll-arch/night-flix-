# 海外短剧 SaaS 第一阶段实现说明

## 已落地

- 中央公共剧池：总部平台剧对所有代理商可见，租户各自审核、国家限制、金币定价、上架与下架。
- 同剧多租户：审核、价格、上架版本和 App 配置全部按 `tenant_id` 隔离，并以版本号做并发保护。
- 内容边界：代理商私有剧不进入公共池；公共剧首次被代理商上架后锁定原内容，变更必须创建带闪创作品/创作者标识的新修订。
- 下架语义：代理商普通下架不改总部剧和其他租户状态；播放策略只允许永久购买者继续观看。总部紧急下架同时停止剧和分集播放。
- App 运行配置：启动接口返回品牌、语言、国家、功能开关、AdMob 广告位和 Apple/Google 商品映射。
- 字幕配音数据层：每集支持多语言字幕和配音轨，字幕限定 WebVTT/SRT/TTML，配音限定音频文件。
- 分成账本：逐剧、分集、租户、创作者、币种和收入类型保存不可覆盖的分成快照；公共剧支持总部/代理商/创作者三方，私有剧为两方，会员收入禁止创作者分成；重复回调幂等，退款可标记回冲。
- Flutter App：Android/iOS 同工程，包含启动、五栏导航、竖滑刷剧、剧场、详情信息、选集、锁集、登录门槛、金币商店入口、任务奖励、搜索、历史、收藏、分享入口、消息/设置入口和个人中心；默认包名与显示名已和闪创主产品隔离。
- 代理商后台：新增公共剧池审核/定价/上下架和 App 运行配置页面。
- 安全播放：继续复用原有短时签名播放 URL、独立预览资源、断点记录和租户权益判断，并允许 HLS MIME 类型。

## 旧框架冲突与处理

| 旧框架行为 | 第一阶段处理 |
| --- | --- |
| H5 + Capacitor 是移动端 | H5 仅保留接口参考；正式客户端为 `apps/flutter_app`。旧壳暂不删除，避免破坏历史内部构建记录。 |
| 平台剧只能由总部逐租户发许可证 | 新增所有租户可见的公共剧池；旧许可证仍兼容历史数据。 |
| 平台剧下架后可再次编辑 | 首个代理商上架即写入不可变锁；后续只能创建新修订。 |
| 播放只认内容许可证 | 同时识别公共剧池发布记录；普通下架仅保留永久购买权益。 |
| App 启动只返回 H5 品牌主题 | 扩展为语言、国家、功能开关、广告位和商店商品映射。 |
| 只有商家结算，没有创作者逐内容分成 | 新增内容收入政策与不可变分成账本。 |
| 原生构建任务复制 Flutter 模板 | 独立构建机从 `apps/flutter_app` 生成代理商 Android 调试包和 iOS 模拟器包；正式商店签名仍由代理商的本地/CI 发布流水线完成，生产服务器不构建。 |

## 需要代理商外部资料后才能完成的真实联调

- Apple Developer、App Store Connect、Google Play Console 的账号、签名和商品 ID。
- Apple Sign in、Google OAuth 客户端 ID 及服务端令牌校验配置。
- 各代理商 AdMob App ID/广告单元、Firebase/APNs 推送配置。
- Apple/Google 沙盒购买、续费、恢复购买、退款通知和真实商店审核。
- 实际 HLS/CDN 鉴权方案、字幕生成服务和配音文件，用于真机连续播放与清晰度/音轨验收。

这些外部项没有用假成功代替；当前代码使用测试配置，并保持主体开发与本地验证可继续进行。服务端未声明安全回执校验能力时，客户端会关闭原生购买入口；OAuth 服务端校验未接通时不会显示 Google/Apple 假登录按钮。
