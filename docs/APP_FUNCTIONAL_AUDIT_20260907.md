## 已验证的实现边界

- 后台私有剧列表和公共剧池均有“权重排行”。权重 -100000～100000，默认 0；置顶顺序 0 表示不置顶、1 最靠前。保存带 expectedVersion，冲突要求重新加载。只有本代理商的 content.drama.update 权限可以改动。
- 首页/排行：置顶顺序优先，其次真实热度 + 运营权重（推荐另加本账号近 30 天分类偏好），最后首次发布时间及 ID。新剧榜不受运营权重干扰。
- 热度不是播放量：有账号的有效观看 100、点赞 200、收藏 300、可见评论 100；同账号同剧同类型去重，7 天半衰期，90 天窗口。游客可读取真实汇总，游客播放暂不贡献评分。预加载、集数、后台权重都不伪造热度。
- 新增 first_published_at 记录新发布；历史数据没有原始上架时间的，按原 release_at/created_at 回填，不声称恢复历史精确时间。公共剧优先按代理商首次上架时间。
- 公共剧的互动读锁复用现有受控锁函数，避免非 owner 账号被 UPDATE RLS 误拦截；显式下架优先于旧授权，紧急下架和地域限制不被权重绕过。
- 客服回复复用反馈 ID 作为消息 ID，事务内一次入箱；新增的 INSERT RLS 仅允许给原反馈作者发送其已保存回复，任意伪造系统消息仍被拒绝。反馈与追剧纳入账号导出/删除路径。
- 截图识剧为端侧文字识别，不是人脸/画面剧情识别；文字不可识别时允许手动输入。没有复制参考 App 的反编译代码或素材。
