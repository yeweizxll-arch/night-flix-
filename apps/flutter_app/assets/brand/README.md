# Original Shanchuang app icon

Generated with the built-in image generation tool for this project, then resized by `flutter_launcher_icons` for Android and iOS.

Prompt summary: an original lightning spark combined with a vertical play symbol; premium minimal 3D gradient; midnight navy, electric violet, magenta and cyan; no people, letters, words, watermark, copied marks or reference-App assets.

`app-icon-master.png` is the editable master used by `pubspec.yaml`. Each agent may replace the master with its own approved brand asset before running:

```bash
dart run flutter_launcher_icons
```
